# Jenkins CI/CD Pipeline

A simple CI pipeline that uses Jenkins and GitHub to automate testing for a JavaScript application.

## Tech Stack

- Jenkins
- Git & GitHub
- Node.js
- JavaScript

## Pipeline Stages

1. Check out the source code from GitHub.
2. Check the Node.js and npm versions.
3. Install project dependencies.
4. Run automated tests.
5. Report the build status.

## Run Locally

Run the test suite with:

```bash
npm test
```

## What I Learned

- How to create a Jenkins pipeline using a `Jenkinsfile`.
- How to integrate Jenkins with GitHub.
- How to automate tests and troubleshoot build failures.
